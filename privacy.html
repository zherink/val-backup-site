Privacy Policy

Last updated: September 23, 2026

Overview

Valheim Backup is a personal application used to automatically upload backups from a privately operated Valheim game server to Google Drive.

Information Accessed

The application uses Google's OAuth authorization system to access Google Drive on behalf of the account owner.

The application only accesses Google Drive for the purpose of storing and managing Valheim server backup files.

How Information Is Used

Google Drive access is used solely to upload Valheim server backup files to the user's Google Drive account.

The application does not sell, share, or disclose user information to third parties.

Data Storage

Valheim backup files are stored in the user's own Google Drive account. The application does not operate an independent cloud storage service or database.

Third-Party Services

The application uses Google Drive and Google's OAuth authorization services. Use of those services is also subject to Google's applicable policies and terms.

Data Deletion

Backup files can be deleted directly from the user's Google Drive account. Access granted to the application can also be revoked through the user's Google Account security settings.

Contact

This application is operated for personal use. For questions about the application, contact the application owner through the associated GitHub account.
